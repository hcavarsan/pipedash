# iOS release

This directory holds the Fastlane lanes, Xcode files, App Store metadata and screenshot editor for the Pipedash iOS app.

- [iOS release guide](https://pipedash.app/docs/resources/ios-release): versions, workflows, secrets, App Review demo access, signing and screenshots.
- [Mobile guide](https://pipedash.app/docs/deployment/mobile): what the iOS app does for users.
