# App Store screenshots

This editor builds the iPhone and iPad App Store screenshot decks from captures of the Pipedash frontend.

- [Screenshot editor guide](https://pipedash.app/docs/resources/app-store-screenshots): editor commands, end-to-end tests, dependency maintenance and headline alternatives.
- [iOS release guide](https://pipedash.app/docs/resources/ios-release#app-store-screenshots): captures, export sizes and Fastlane publishing.
